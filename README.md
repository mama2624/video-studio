# 🎬 진진 숏폼 편집기 (video-studio)

지연님 전용 **9:16 세로 · 16:9 가로 숏폼 영상 편집기**.
설치·로그인·서버 없이 **브라우저에서만** 동작하고, 편집한 영상은 **MP4**로 내려받습니다.

- 주소: <https://mama2624.github.io/video-studio/>
- 만든 방식: HTML/CSS/JS 정적 파일 + GitHub Pages (서버·API 키·결제 없음, 0원)
- 영상·사진·목소리는 **기기 밖으로 나가지 않습니다** (모든 처리는 브라우저 안)

---

## 1. 무엇을 할 수 있나

| 기능 | 내용 |
| --- | --- |
| 사진·영상 | 여러 개를 한 번에 올려 순서대로 이어 붙임 (MP4·MOV·WebM·JPG·PNG·WebP) |
| 타임라인 | 클립 선택 · **분할(컷)** · 삭제 · 앞/뒤 순서 이동 · **시작점/길이 트림** |
| 화면 비율 | **9:16 세로**(1080×1920, 쇼츠·릴스·클립) ↔ **16:9 가로**(1920×1080, 유튜브) |
| 구간 자막 | 시작·끝 초, **글자 크기 대폭 확대**, 줄바꿈, 위치 드래그 |
| 폰트·디자인 | 한글 웹폰트 12종(주아·검은고딕·도현·나눔명조 등), 색·외곽선·그림자·반투명 배경박스·둥글기·자간·줄간격 |
| 스티커 | **투명 PNG/JPG 업로드**, 크기·회전·투명도·표시 구간 |
| 상단 타이틀 | 영상 내내 위에 붙는 훅 문구(1~2줄) |
| 안전영역 | 쇼츠·릴스·네이버 클립 아이콘/설명에 가려지는 영역 표시(세로 모드) |
| 내 목소리 | **🎙️ 마이크로 바로 녹음**해 나레이션 트랙으로 (시작 위치·음량 조절) |
| 음성 파일 | **🗣️ MP3·M4A·WAV**를 나레이션 트랙으로 (BGM과 분리) |
| 배경음악 | 음원 업로드 + 볼륨·페이드 인/아웃·반복 |
| 원본 소리 | 영상 원음 음량 조절 / 음소거 토글 |
| 글 → 자동 자막 | 블로그 글을 붙여넣으면 **4~8개 구간 자막 + 상단 타이틀**을 영상 길이에 맞춰 자동 생성 |
| 저장 | **MP4(H.264)** — 지원 브라우저는 AAC, 미지원이면 Opus / 아주 오래된 브라우저는 WebM |

### 오디오는 3층으로 섞입니다
`원본 영상 소리` + `내 목소리(녹음·음성 파일)` + `배경음악` → 저장할 때 **한 파일로 믹싱**됩니다.
(볼륨·페이드·시작 위치가 모두 반영됩니다)

> 🔊 **대본 미리 듣기(브라우저 읽어주기)** 는 *미리듣기 전용*입니다.
> 브라우저 보안 구조상 그 소리는 캔버스 녹화에 합쳐지지 않으므로, 실제 나레이션은
> **직접 녹음** 또는 **음성 파일 업로드**로 넣어야 영상에 들어갑니다.
> 앱 안에도 같은 안내가 표시됩니다.

## 2. 쓰는 순서

1. **＋ 사진·영상** (또는 화면에 파일 끌어다 놓기) → 타임라인에 클립이 쌓입니다.
2. 클립을 눌러 **분할·순서·길이**를 다듬습니다.
3. **구간 자막** 탭에서 `＋ 자막 추가` → 내용 입력 → 미리보기에서 **끌어서 위치**, 두 손가락으로 **크기**.
   - 블로그 글을 붙여넣어 한 번에 만들려면 **📝 글 → 자동 자막**.
4. **폰트·디자인** 탭에서 글꼴·색·외곽선·배경박스를 정하고 `모든 자막에 적용`으로 통일.
5. **스티커 / 상단 타이틀 / 오디오·음성** 탭으로 살을 붙입니다.
6. **⬇ MP4 저장** → 화질 선택 → 저장 시작.
   - 저장하는 동안 영상이 처음부터 **실제로 재생**되며 녹화됩니다(영상 길이만큼 걸립니다).
   - 그동안 **화면을 켜 두고 다른 앱으로 전환하지 마세요.**

## 3. 저장 형식 안내

| 브라우저 | 결과 |
| --- | --- |
| 크롬·엣지·삼성 인터넷·웨일 (최신) | **MP4 (H.264)** — 소리는 AAC(있으면) 또는 Opus |
| 사파리 16.4+ | **MP4 (H.264 + AAC)** |
| 아주 오래된 브라우저 | **WebM (VP9+Opus)** — 유튜브 업로드 가능, 인스타는 MP4 권장 |

- 인코딩은 `WebCodecs`(H.264) → 안 되면 `MediaRecorder` 순서로 자동 선택합니다.
- AAC 인코더가 없는 환경(예: 리눅스 크롬)에서는 소리가 **Opus**로 들어갑니다.
  유튜브·크롬·안드로이드에서는 정상 재생되지만, 일부 앱은 AAC만 받습니다.
- 30fps 고정, 1080×1920 / 720×1280 (가로는 1920×1080 / 1280×720).

## 4. 알아 둘 점

- **블로그 URL을 직접 긁어오지 않습니다.** 정적 웹앱은 다른 사이트를 읽을 수 없어(CORS),
  제목·본문을 **복사해 붙여넣는** 방식입니다.
- 폰트는 Google Fonts·Pretendard CDN에서 받아옵니다. 인터넷이 끊기면 기본 글꼴로 보입니다.
- 아주 긴 영상(3분 이상)은 브라우저 메모리·발열 때문에 나눠 저장하는 편이 안전합니다.
- iOS 사파리는 화면이 잠기면 녹화가 멈출 수 있습니다(저장 중 화면 유지 필요).

## 5. 파일 구성

```
index.html          화면 뼈대 (헤더·미리보기·타임라인·5개 탭·모달)
css/style.css       스타일 (모바일 세로 우선 + PC 2단 반응형)
js/app.js           편집 상태·캔버스 렌더·타임라인·오디오 믹싱·내보내기
js/mp4-muxer.js     MP4 컨테이너 생성 라이브러리 (mp4-muxer v5, 오프라인 동작)
.nojekyll           GitHub Pages Jekyll 처리 생략
```

## 6. 배포

`main` 브랜치 루트를 GitHub Pages로 배포합니다.

```bash

cd video-studio
# 파일 수정 후
git add -A && git commit -m "..." && git push origin main
```

배포 후 1~2분 뒤 <https://mama2624.github.io/video-studio/> 에 반영됩니다.
